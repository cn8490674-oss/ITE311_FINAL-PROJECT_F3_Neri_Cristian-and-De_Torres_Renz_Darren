# BantayTicket

**Project Title:** A Web-Based Barangay Complaint and Request Ticketing System with CMS Integration and Resident Status Tracking for Barangay Bagong Buhay

**Student Name:** Cristian M. Neri and Renz Darren M. De Torres

**Course and Section:** BSIT 3/F3

## Project Description

BantayTicket is a proposed web-based system for Barangay Bagong Buhay that organizes residents' complaints and service requests. It provides ticket records, reference numbers, and status tracking to help authorized barangay personnel monitor each concern. Its CMS component can manage public announcements and barangay information.

## Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub

## Main Features

- Resident profile records
- Complaint and request ticket management
- Ticket status tracking
- Input validation
- CMS-managed announcements
