# Ticket Validation Feature

## Purpose
Check ticket information before it is saved.

## Validation Rules
- Resident information must be provided.
- A complaint or request category must be selected.
- The description must not be empty.
- Each ticket number must be unique.
- A new ticket starts with the Submitted status.
- Status updates must use approved status values.

## Benefit
Validation helps prevent incomplete or inconsistent ticket records.
